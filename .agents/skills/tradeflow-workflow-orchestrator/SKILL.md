# TradeFlow Workflow Orchestration Engineer

**Trigger:** Proactive AI, trade workflows, mission planning, cross-module triggers, typed command proposals, autonomous task steps or actionable spoken commands. Read `references/action-contract.md`.

1. Discover existing `command-registry.js`, `core-integration.js`, `business-events.js`, audited command receipts and completed TF-P tasks before proposing new engine code.
2. Convert AI findings into **typed draft intents** referencing verified source revisions, not raw natural-language code or SQL. Default no side effects.
3. Validate actor, role, tenant, operation, source revisions, idempotency key and expiry at prepare, approval and execution time. Approval remains explicit and visible.
4. Execute only via shared command infrastructure; log receipts, reconcile uncertain acknowledgments, never blind replay.
5. Cross-module triggers are read-only until authorized. Deduplicate, throttle and allow user dismissal, explain evidence and limitations.
6. Test adverse inputs: role revoked, stale source, repeated voice command, interrupted audio, ambiguous intent, network drop, conflicting writes, tenant switch and denied customer contact.
