Limits of this evidence

  • Every world is a small simulator written by the same team as the candidate; results are synthetic and say nothing about real contractors or machines.
  • Zero language-model calls were made; nothing here is live model learning.
  • The referee runs in the same Python process as the candidate. Module separation is not a security boundary against hostile code.
  • Outcome memory fits one additive correction per declared decision component; it cannot represent context-dependent or subject-level hidden rules.
  • 'Harmful' means realized worse than no action on matched shocks, so prudent preventive spend that turned out unnecessary is counted as harm.
  • The holdout-reuse guard only sees the local run history in the output folder.
  • Latency is in-process Python on small option sets, not model or network latency.
